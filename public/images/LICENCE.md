# Stock hero pool — licence note

All images in this folder are free stock photos under the **Pexels License**
(free for commercial use, no attribution required). Attribution is recorded
here anyway, per the site's photo plan
(`beat-sir-complete-plan-2026-11-16.md` §1.2–§1.3).

**Hard rules for use:** these are GENERIC illustrative photos. Never caption
any of them as a specific town, street, house, or job. Never present the
suburban-house photo as a home in any particular town. Every published use
must carry the source line given below. No house numbers, licence plates, or
recognisable private homes are shown as examples.

All files were downloaded 2026-11-16 from the Pexels CDN
(`images.pexels.com`) at 1600 px wide and verified as real JPEG image bytes
with `file`. Source page URLs below are the exact Pexels photo pages, found
via web search 2026-11-16; photographer names and photo descriptions are
as stated on those pages.
